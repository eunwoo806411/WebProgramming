- 임시 폴더: `/private/tmp/soongsil-one-frame-preview`
- 웹서버: `http://127.0.0.1:8001`
- Chrome PC 화면에서 확인. 사용자 변경 요청에 따라 모바일 구현·검증 제외.

## 확인한 항목
- 루트에서 로그인 이동, 공통 메뉴로 등록·마이페이지·탐색·메인 이동.
- 비로그인 둘러보기, 개발용 테스트 로그인, 로그아웃, 비로그인 재입장.
- 실제 숭실대 중심 배경 지도 표시, 키보드 지도 이동, 이동 후 마커 좌표 유지.
- 타일 없는 검증 화면에서 확대 17 → 18 → 21: 마커 묶음 5 → 6 → 10개. 서로 다른 좌표 분리, 같은 좌표 3장 유지와 목록 열기.
- 묶음에서 사진 상세 이동. 촬영·업로드 시각, 장소, 좌표 표시. 작성자 계정 정보는 표시하지 않음.
- 비로그인 좋아요 제한. 테스트 로그인 시 45 → 46 증가, 새로고침 후 유지, 해제 후 45 복원.
- 좋아요로 목록이 다시 그려진 후 모달을 닫아도 같은 사진으로 키보드 초점 복원.
- 날짜 입력 → 슬라이더 값 갱신, 슬라이더 키보드 조작 → 날짜 갱신.
- 9월 22일 09~18시 양쪽 경계 포함 4장, 같은 시작·끝 시각 1장.
- 날짜를 넘는 범위 5장, 1초 뒤로 시작을 옮긴 빈 결과, 역순 오류·마커 0개, 전체 기간 초기화 12장.
- 탐색 기본 화면에서 최신순·인기순 설명 전환.
- 최종 페이지 이동 과정에서 수집된 브라우저 error 로그 없음.
- Node 핵심 테스트 9/9 통과: 저장 유지·실패·손상·사용자 분리·익명 입장, 한국 시간, 경계 필터, 정렬, 군집.

## 검토에서 발견해 수정한 항목
1. 좋아요 후 재생성된 카드·마커로 모달 초점을 돌리지 못함: 안정된 초점 키로 재탐색. 수정 전 BODY 초점, 수정 후 photo:demo-12 카드 초점을 브라우저에서 확인.
2. 저장 차단 환경에서 이미 비로그인인데도 로그아웃 쓰기를 시도함: 이미 비로그인이면 쓰지 않도록 수정. 실패 테스트를 먼저 확인한 뒤 9/9 통과. 실제 세션 삭제 실패는 계속 오류 처리.

## 제한 및 후속 확인
- 사진 등록·마이페이지 조회·전체 목록 조회·실제 로그인은 의도적으로 기본 틀만 구현.
- 지도/이미지 네트워크 실패 안내 코드는 검토했으나 실제 네트워크 차단 상황을 브라우저에서 강제로 재현하지는 않음.
- 브라우저 저장 차단은 주입 가능한 저장 어댑터의 자동 검사로 확인했으며 Chrome 설정 자체를 변경하지 않음.
- 모바일 제외. 작은 화면에서는 PC 최소 폭 1100px 유지.
- 위 검증은 임시 폴더에서 수행했으며, 이후 사용자 요청으로 같은 구현을 팀 저장소에 반영했습니다.
