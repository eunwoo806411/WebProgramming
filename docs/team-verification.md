# 팀원 기능 확인 안내

## 실행
Node 22에서 `npm ci`, Supabase 설정 `.env` 준비, SQL 0001/0002 순서 적용 후 `npm start`. 로그인 API는 GitHub Pages에서 실행되지 않는다. 실제 서버 키/DB 비밀번호가 있는 `.env`는 공유 저장소에 올리지 않는다.

현재 기능은 로컬 기능 브랜치 `codex/main-backend`에 있으며 main 병합/공개 배포는 별도다.

## 확인 순서
1. 비로그인: 메인 지도/기간, 전체 사진, 상세 조회. 좋아요·등록·마이페이지는 로그인 필요.
2. 학교 계정 로그인: 새로고침 로그인 유지, 로그아웃 뒤 쓰기 차단. 학교 비밀번호는 학교 사이트에서 관리.
3. 사진 등록: JPG/PNG/WEBP 8MB 이하, 건물 또는 지도 위치, 촬영 시각과 설명. 등록 후 상세/지도/전체 사진에서 확인.
4. 메인: 최근 기간/전체 기간, 지도 이동/확대·축소, 사진 묶음, 10장 더 보기, 상세 좋아요와 취소.
5. 마이페이지: 내 사진 장소/설명 수정, 삭제, 좋아요한 사진에서 취소. 각각 지도·받은 좋아요·업로드 수·등급·통계에도 반영되는지 확인.
6. 계정 정보: 닉네임 수정 후 재로그인, 닉네임 유지. 기존 사용자 가입일은 새 프로필이 처음 생성된 날짜부터 기록된다.
7. 전체 사진: 최신순·인기순, 24장 더 보기, 상세 좋아요 변경. 실시간 좋아요로 인기 순위가 바뀌면 새로고침해서 현재 순위를 다시 확인.
8. 서로 다른 두 계정으로 상대방 사진 수정/삭제 불가 확인. 삭제된 사진은 새로고침 및 직접 상세 주소 접근 시 보이지 않아야 한다.

## 오류 제보
접속 주소, 페이지/버튼, 기대한 결과와 실제 결과, 재현 순서를 함께 남긴다. 키·DB 주소·학교 비밀번호는 첨부하지 않는다.

## 검증 기록 (2026-11-06)
로컬 HTTP + SQLite, embedded PostgreSQL SQL, jsdom HTML 연결 테스트와 실제 Supabase 임시 사진 등록/읽기/수정/좋아요/취소/삭제를 확인했다. 실제 학교 로그인은 사용자 수동 확인을 바탕으로 기존 방식을 유지했으며, 자동 테스트는 외부 인증 경계를 대체한다. 브라우저 연결 도구가 작동하지 않아 실제 브라우저의 화면 배치와 Leaflet/트랙패드 상호작용은 자동 검증하지 못했다.
