카카오 지도 연결

키 없이도 가상 지도에서 모든 데모 기능을 체험할 수 있어요. 실제 지도를 사용하려면 Kakao Developers에서 발급한 JavaScript 키를 입력하세요.

① Kakao Developers 앱에서 지도 사용 설정을 확인하세요.
② 웹 플랫폼에 실행 도메인(예: http://localhost:8000)을 등록하세요.
③ 이 HTML이 있는 폴더에서 python -m http.server 8000을 실행하고 localhost:8000으로 접속하세요.
④ REST API 키나 Admin 키는 입력하지 마세요.

키는 이번 페이지 실행 중에만 사용하며 별도로 저장하지 않습니다. 학교 인증은 APP_CONFIG의 server 모드에서 외부 인증 서버에 연결합니다. 인증 서버와 학교 SSO 설정은 별도 준비가 필요합니다. 서버 업로드·회원 간 데이터 공유는 구현되지 않은 데모입니다. 사진과 좋아요는 localStorage에 저장되며, 브라우저 데이터를 지우면 사라집니다.
